# Statistics & Probability — MATLAB Assignment

MATLAB implementation for seven questions completed as part of a Software Engineering assignment.

## Questions
1. Q1 — Variables, Measurement Scales and Measurement Error
2. Q2 — Simple Random, Stratified and Systematic Sampling
3. Q3 — Discrete Frequency Distribution
4. Q4 — Grouped Frequency Distribution of API Response Times
5. Q5 — Grouped Frequency Distribution of Programming Scores
6. Q6 — Stem-and-Leaf Display and Central Tendency
7. Q7 — Arithmetic Mean, Weighted Mean, Median and Mode

## How to run
Open MATLAB, set this repository folder as the current folder, open any question's `.m` file, and click **Run**. Each script prints results and creates the required graph(s).

Q2 selects random IDs, so its exact sample changes between runs. Q6 includes code to identify all tied modes because MATLAB's built-in `mode` returns only one value.

# Q2 — Sampling Methods

Population: A=60, B=50, C=70, D=60; total N=240; sample n=24.

- Simple random sampling: select 24 IDs from 1–240.
- Proportional stratified allocation: A=6, B=5, C=7, D=6.
- Systematic sampling: k=N/n=10; choose a random start from 1–10 and select every 10th ID.

Run `Q2_Sampling_Methods.m`. Random IDs may change each run.

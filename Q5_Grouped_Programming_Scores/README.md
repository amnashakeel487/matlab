# Q5 — Grouped Programming Scores

For 50 scores, minimum=42, maximum=96, range=54. Use class width 10.

Expected classes/frequencies: 40–49:3, 50–59:7, 60–69:10, 70–79:12, 80–89:12, 90–99:6.

The script creates a histogram, frequency polygon and cumulative frequency curve. Run `Q5_Grouped_Programming_Scores.m`.

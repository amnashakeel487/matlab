# Q6 — Stem-and-Leaf and Central Tendency

For 25 execution times: mean=27.76 seconds, median=27 seconds, modes=21, 24 and 28 seconds.

The stem is the tens digit and the leaf is the ones digit (for example, `2 | 7` means 27). The script also plots a boxplot and histogram. MATLAB's built-in `mode` returns one tied mode, so the script calculates all modes separately.

Run `Q6_Stem_Leaf_and_Central_Tendency.m`.
